# ⚠️ Товарные знаки третьих лиц

Эта папка — зеркало каталога [pheralb/svgl](https://github.com/pheralb/svgl) (сам код каталога — MIT license).

**Важно:** SVG-файлы внутри `static/library/` — это логотипы реальных компаний (Apple, Google, Adobe, GitHub, Stripe и 1000+ других). Каждый логотип является товарным знаком (trademark) своего правообладателя, а не объектом MIT-лицензии репозитория.

## Правила использования внутри NUR

- Хранение здесь — только для внутренней справки/идентификации бренда в приватном репозитории, не для публичного распространения.
- **Не использовать** логотип чужой компании как элемент собственного дизайна, как будто он принадлежит NUR, и не подавать так, будто есть партнёрство/поддержка от этой компании (это может быть воспринято как ложное указание на аффилированность).
- Публикация/показ логотипа наружу (сайт, презентация клиенту, соцсети) — только в контексте, где использование очевидно допустимо (например, «мы интегрируемся с Stripe» рядом с логотипом Stripe, по правилам добросовестного использования конкретного бренда) — и лучше свериться с брендбуком конкретной компании перед публичным использованием.
- Перед коммерческим/публичным применением конкретного логотипа — проверить guideline самой компании (у большинства крупных брендов есть отдельная страница «Brand Guidelines» / «Press Kit»).

Репозиторий приватный — риск минимален, но пометка оставлена намеренно, чтобы не забыть при переносе в публичные материалы.
